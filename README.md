Customer Churn Analysis
Overview

This project analyzes customer churn data to identify the key factors influencing customer retention and churn. Using Python for Exploratory Data Analysis (EDA), SQL for querying insights, and Power BI for interactive visualization, the project uncovers patterns that help businesses improve customer retention strategies.

Objectives
Analyze customer demographics and subscription behavior.
Identify the major factors contributing to customer churn.
Perform data cleaning and exploratory data analysis.
Generate business insights using SQL queries.
Build an interactive Power BI dashboard for decision-making.

Key Insights
Customers with month-to-month contracts are significantly more likely to churn.
Customers paying through electronic checks exhibit the highest churn rates.
Higher monthly charges are associated with increased customer churn.
Customers with longer tenure are more likely to remain loyal.
Lack of Tech Support and Online Security services is linked to higher churn.
Customers using Fiber Optic Internet have comparatively higher churn rates.
